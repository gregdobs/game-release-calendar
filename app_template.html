Ranking source

Live ranking replaces the built-in editorial hype scores with RAWG's added metric — how many RAWG users have the game in a library or wishlist. It needs a free API key.

  1. Register at rawg.io/apidocs (free, no card).
  2. Copy the key from your RAWG profile page.
  3. Paste it below and press Save & test.
  4. Press Fetch live ranking. Takes about a minute for all 875 titles.

The key is stored only in this browser's localStorage — it is never written into index.html, so rebuilding or sharing the file cannot leak it. Results are cached locally, so you only pay the fetch once.
